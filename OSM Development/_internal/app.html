OSM DevelopmentGera a página de repasse a partir do Git ou de um diff

Abrir visualizador

1De onde vem o desenvolvimento

Cole o caminho da pasta do repositório (a mesma onde você roda os comandos git) e carregue os commits.

Marque o primeiro commit da demanda. Ele e todos os mais recentes, acima dele, entram no diff.

Envie um diff do Git, bruto ou já compactado.

Arraste o arquivo de diff aqui
ou clique para escolher

2Nome da demanda

Aparece no topo da página. Se já existir uma explicação com este nome, ela é usada automaticamente.

3Explicação opcional

Texto que explica a demanda, em Markdown (.md) ou HTML. Fica salvo na pasta explicacoes para as próximas vezes. Baixar o modelo
